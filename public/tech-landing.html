Section 01

Executive summary

UnScribble converts photos of handwritten prescriptions into structured JSON for pharmacist review — with confidence scores, human-review flags, and formulary validation.

Property Value
Runtime Node.js >= 18 (no bundler, no build step)
AI provider NVIDIA NIM (OpenAI-compatible Responses API)
Default model openai/openai/gpt-5.5
Agents 7 specialized steps (5 vision/text LLM, 2 deterministic)
Frontend Vanilla ES modules in public/
Deployment Stateless HTTP server (server.js), Render-ready
Primary API POST /api/decode/stream (SSE)

Transcription aid only. Not a clinical decision system — all medication data must be verified by a licensed clinician or pharmacist.

flow
Section 04

Decode pipeline

The orchestrator runs agents in stages; parallel stages use Promise.all. Critical agents (raw_transcription, medications) fail the whole workflow on error — others degrade with empty sections.

Stage Agents Execution Purpose
1 image_quality Sequential Quality gate; early exit on unusable
1b raw_transcription Sequential OCR + region_hint inference
2 patient_header, medications, clinical_context Parallel Structured extraction with region bias
2b medications Conditional Self-consistency re-run on low confidence
3 safety_review Sequential Deterministic rules
4 synthesis Sequential Plain-language summary (LLM or template)
Post — Sequential Formulary dedup, fuzzy match, auto-correct

Self-consistency (Stage 2b)

A second medications pass runs when a first-pass row has confidence < 0.7 or uncertainty markers (skipped past 6 rows). The re-run uses a temperature nudge and a focused LASA block; mergeMedicationRuns reconciles line by line.

wire protocol
Section 05

Request & response flow

The browser enhances the image, posts it, and consumes a Server-Sent Event stream until the final workflow.complete arrives.

workflow.start

{ workflowId, agents: [{ id, label }] } — UI builds the per-agent checklist.

agent.start

{ id, label } — agent enters its stage; no PHI on the wire.

agent.complete

{ id, durationMs, summary, nimRequestId? } — row flips to done.

agent.error

{ id, message, rawText? } — non-critical agents degrade to empty sections.

workflow.complete

{ result, workflow: { steps, totalMs, model, cached? } } — final merged result.

workflow.error

{ message, agentId? } — emitted when a critical agent fails.

Every event carries requestId, mirroring the HTTP X-Request-ID header.

decode request body 
{
  "imageDataUrl": "data:image/jpeg;base64,...",
  "originalImageDataUrl": "data:image/jpeg;base64,...",
  "fileName": "rx-photo.jpg",
  "enhancementMode": "original | contrast | mono"
}
the team
Section 06

Agent design

Each agent exports { id, label, critical?, deterministic?, run(ctx) }. LLM agents go through runVisionAgent / runTextAgent in run-agent.js.

Agent Type Critical Input
image_quality Vision No Prescription image
raw_transcription Vision Yes Image + quality context
patient_header Vision No Image + raw transcription
medications Vision Yes Image + med lines + region hint
clinical_context Vision No Image + transcription
safety_review Deterministic No Merged artifacts
synthesis Text No Merged JSON summary input

Prompt-cache optimization

Region directives and buildUserContextBlock are appended to user content, not system instructions — so system prompts stay stable and cacheable.

Structured output

All LLM calls use text.format.type = "json_schema" with strict: true. Reasoning tokens are omitted on structured calls so JSON isn't starved of max_output_tokens.

Section 07

Result contract

merger.js produces the object consumed by results.js and medication-details.js.

DecodeResult 
type DecodeResult = {
  summary, raw_transcription, region_hint,
  patient, medications: Medication[], allergies,
  clinical_context, abbreviations, non_medication_text,
  follow_up_instructions, global_warnings, image_quality,
  requires_human_review, review_reason
}

type Medication = {
  medication_name, medication_name_raw, medication_name_confidence,
  strength, dose, frequency, normalized_frequency,
  confidence, alternatives[], low_confidence,
  requires_verification, safety_flags[]
}

Formulary post-processing

1

Deduplicate

Collapse rows sharing the same identity key.

key = name + "|" + strength + "|" + form (lowercased)
2

Distance-1 auto-correct

A single unambiguous match is promoted into medication_name; the original is preserved in medication_name_raw.

levenshtein(raw, entry) === 1 && matches.length === 1 → promote
3

Ambiguous → alternatives

When candidates tie, the name is left untouched and close matches are appended as alternatives.

4

No match → cap & flag

Unknown names have confidence capped and are flagged, feeding requires_human_review.

Section 10

Workflow caching

A content-hash LRU avoids re-decoding identical images within the TTL.

Behavior Detail
Disabled when WORKFLOW_MOCK=1 or WORKFLOW_CACHE_DISABLE=1
Cache hit Single workflow.start + workflow.complete (cached: true); no per-agent events
Stored runs Successful, non-early-exit decodes only
